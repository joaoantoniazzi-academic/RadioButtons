# RadioButtons
Uma aplicação .NET MAUI para a disciplina de Programação para Dispositivos Móveis para testar serialização e desserialização de valores JSON.

## Para rodar
É preciso ter a CLI `dotnet` instalada.
Para um _build_ bem-sucedido, remova as pastas `bin` e `obj`, compile e então execute novamente:

```bash
rm -rf bin obj
dotnet build
dotnet run
```

> No caso de dúvidas, consulte o material disponibilizado pela Microsoft em https://learn.microsoft.com/pt-br/dotnet/core/tools/
